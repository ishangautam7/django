About This Project

This Task Manager application is built using Django framework following the MVT (Model-View-Template) architecture.

MVT Architecture:

  • Model: Defines the data structure (Task model with fields)
  • View: Handles business logic and processes requests
  • Template: Renders the HTML pages for the user

Technologies Used:

  • Python & Django
  • SQLite Database
  • HTML/CSS Templates
